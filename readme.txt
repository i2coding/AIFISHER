----------------------------------------------------------------
怎么启动
----------------------------------------------------------------
构建与启动都必须用 Node 24.20.0（精确匹配，不是 >=）。

  cd /d D:\source\AIFISHER
  npm run desktop:dev

这句会自动切到 24.20.0、重新构建、拉起窗口。改完前端要再跑一次（没有热更新）。

Node 不在默认位置时：
  AIFISHER_NODE      指向 node.exe
  AIFISHER_NODE_DIRS 多个安装根目录，分号分隔

其它命令：
  npm run typecheck   类型检查
  npm run unit        单元测试
  npm run build:stable  只构建前端


----------------------------------------------------------------
四条红线
----------------------------------------------------------------
1. scripts/runtime/ 是作者故意剔除的（发行策略，见 SOURCE-SCOPE.md）。
   现在目录里那份是本地补的实现，不是原版。别去找原版、别把它当 bug 上报。

2. Node 必须 24.20.0。vite.stable.config.ts 开头就硬校验，版本不对直接抛错。

3. 没有 dev server、没有热更新。桌面壳永远读 dist/ 里的静态文件。

4. 在受限环境（沙箱）里直接构建，会先清空 dist/ 再失败，导致应用白屏。
   必须临时关掉 emptyOutDir 再构建，做法见 AGENT-NOTES.md §1.4。
   绝不要 rm -rf dist。
